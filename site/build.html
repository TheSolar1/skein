Build your own node, as cheaply as possible

A Skein node is a small LoRa radio plus a computer that runs the Skein software. You do not need a licence in France for the 868 MHz band at the default power.

No internet needed

The Skein software itself never needs internet. Nodes find each other over any local link: a LoRa radio, a Wi-Fi or Ethernet network (even a phone hotspot or a router with no internet), or a Wi-Fi bridge between two buildings. On a shared network they discover each other automatically (port 7777). The node panel and the .skein pages are served from your own machine. Only this map needs internet (map tiles, terrain and node lists), so use it to plan, not to run the network.

Range or speed: pick your link

No radio does both. Meshtastic (LoRa) reaches very far but carries only about 1 kbps: fine for messages, painful for files. For lots of data you need a Wi-Fi link, which is 10 000 times faster but needs line of sight. Skein already runs over both at once and sends big transfers over the fast link.

Even cheaper: Bluetooth, nothing to buy

Phones and laptops already have Bluetooth, so nearby devices could form a small Skein network with no extra hardware (the idea behind BitChat). Range is short, roughly 10–50 m per hop, but every device can relay for the next one. This is not built yet: today Skein only talks to Meshtastic radios and over the internet (UDP). It is the next transport on the list.

Where height matters more than money

Radio range depends mostly on how high the antenna is and on terrain in the way. A 20 € node on a roof or window sill often beats a 100 € node in a basement. Use the map to see the zone around where you want to put it before buying anything.

Set it up

  1. Connect the antenna before powering the board.
  2. Flash Meshtastic from flasher.meshtastic.org (in a Chromium-based browser) and set the region to EU_868.
  3. Download Skein and build it: cargo build --release in the infra folder (see the repository).
  4. Run skein run --serial COM5 (your port may differ). Over Wi-Fi instead: skein run --mesh IP-OF-THE-BOARD:4403.
  5. Open http://127.0.0.1:8080/ for the node panel: your address, neighbours, routes and names.
  6. Back on the map, place your node and use « Export my nodes » to share its position.
Good to know
  • Never transmit without an antenna attached: it can destroy the radio.
  • Keep the default power and settings. In France the 868 MHz band is licence-free but limited in power and airtime.
  • The Skein software runs on the computer, not on the radio board itself yet. The radio-over-serial link is written but has not been tested on real hardware.
